# CRM Auto — веб-интерфейс (S01/S03)
Реализованы: вход по сессии, рабочее пространство компании, переключение компаний,
главная без выдуманных финансовых цифр, список/создание клиентов и автомобилей.
Неактивные модули обозначены как «в разработке», не используются фиктивные оплаты.
Интерфейс адаптирован для мобильного браузера.

Локально: запустите backend на localhost:8000; затем `cd frontend && npm install && npm run dev`.
Vite проксирует /api на Django. Не используйте dev-сервер для коммерческого развёртывания.
Чтобы авторизоваться, создайте тестового пользователя после применения миграций, в изолированной dev-среде.

Ограничения: lock-файл зависимостей и E2E/UX тесты ещё не включены; проверка браузера обязательна перед DONE.
Самостоятельная регистрация заблокирована в интерфейсе до подтверждения email.
