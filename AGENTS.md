# Правила для AI-разработчика (обязательные)
Источник: мастер-ТЗ v5.0. Границы первого релиза — docs/ROADMAP.md.
- Без GitHub Actions, коммиты прямо в main только после ручной проверки.
- Запрещено создавать видимость готового модуля: UI без API/БД/разрешений/тестов не считается завершённым.
- Не придумывать финансовые/правовые решения без ADR. Не менять статусы без тестов.
- Не доверять tenant_id, branch_id, role или price из клиентского запроса. Разрешения серверные.
- Резерв != списание; запись != визит != заказ-наряд; начисление != оплата.
- Изменение учётных фактов только в транзакции с идемпотентным ключом; журнал аудита и событие outbox.
- Не удалять историю финансов, складских движений или владельцев автомобилей.
- По спринту: миграции, API, frontend, error states, ограничения и тесты; итог в docs/sprints.
- Production: PostgreSQL, TLS, секреты из окружения, административный MFA, резервное копирование, восстановление.
- Платные live probes, LLM и CI-пайплайны не запускать.
