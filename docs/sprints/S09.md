# S09 — аналитика и Центр потерь: IN PROGRESS
Реализовано: read-only API по филиалу /api/v1/reports/finance и /api/v1/reports/losses, разделение выставленных сумм, денежных поступлений, возвратов и остатков задолженности. Ролевая и межарендная проверка на сервере. Набор начальных правил: неоплаченные начисления, заказ-наряды старше 7 суток, зависшие резервы старше 3 суток.
ЗАПРЕЩЕНО называть эти метрики чистой прибылью, выручкой по РСБУ или подтверждённой банковской кассой; нет корректных себестоимости и расходов. Пороговые значения предварительные, не утверждены бизнесом.
Не завершены: приёмочные тесты PostgreSQL, сверка с банковскими выписками, затратные партии, расчёт рентабельности, UI и фоновые отчёты.
