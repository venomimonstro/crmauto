# S13 — Портал владельца автомобиля — IN PROGRESS
Разработано: отдельная привязка user→customer→organization (PortalGrant), по умолчанию неактивная; чтение действующих автомобилей и заказ-нарядов пользователя без X-Organization-ID; только опубликованные версии смет; всё в режиме чтения.
Критические ограничения: механизм доказуемого подтверждения принадлежности клиента и включения PortalGrant не реализован, поэтому нельзя автоматически активировать связь по телефону/email/VIN. Онлайн-запись и согласование сметы также закрыты до авторизованного процесса подтверждения личности. Владелец автомобиля не может сам получить доступ через неподтверждённые совпадения.
ДО DONE: независимый auth-онбординг автовладельца, отзыв доступа, ручная проверка персонала, исторические владельцы, уведомления, UI и интеграционные/межарендные тесты на PostgreSQL.
