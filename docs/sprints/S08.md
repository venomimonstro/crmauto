# S08 — Финансовый контур: IN PROGRESS
Реализовано: начисление (Invoice) только по согласованной ненулевой смете; MoneyMovement отдельно от начислений, частичная оплата, защита от переплаты, возврат по исходной оплате с ограничением на сумму ранее уплаченного, роль кассира, серверная изоляция компаний и филиалов, идемпотентные операции, журнал аудита.
НЕРЕАЛИЗОВАНО: проверка внешнего эквайринга и банковских платежей, фискализация, корректировка цены после начисления, полноценные расходы/кассовые смены, закрытие периода, UI, реальные PostgreSQL тесты и e2e. Эти операции нельзя выдавать за реальные банковские транзакции. Production недопустим.
