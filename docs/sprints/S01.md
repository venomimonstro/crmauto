# S01 — архитектурный каркас
Реализовано: Django/DRF, health/liveness/readiness, PostgreSQL-only по умолчанию, конфигурация безопасности, Docker Compose (локальная разработка), пример переменных окружения, базовый тест, дорожная карта.
Проверки: Python compileall, git diff; интеграционный запуск требует скачивания зависимостей и Docker.
Риск: отсутствие live PostgreSQL/docker в среде разработки. **Не объявлять S01 DONE до воспроизведения среды и миграций.**
Отложено: RBAC и реальная CRM (следующие спринты).
