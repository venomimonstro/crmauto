# S05 — Приёмка, сметы и заказ-наряды — IN PROGRESS
Реализовано: WorkOrder привязан 1:1 к фактически открытому Visit; снимок клиента и автомобиля; жалоба, пробег, дефекты; черновик сметы; позиции работ, плановые материалы (без фиктивного складского списания), подрядчики; суммы целыми копейками; ревизии смет, блокировка изменения отправленных и согласованных смет; журнал переходов и аудит; атомарные, идемпотентные операции. API /api/v1/workorders.
Статусы: draft→awaiting→approved→in_progress→qa→ready. Возвраты qa→in_progress, ready→in_progress. Согласование фиксирует reference (доказательство вводит сотрудник, пока нет клиентского портала). Принудительная выдача до кассы/документов S08 запрещена.
Не готово: интерфейс заказ-наряда; вложения и приёмочный акт, фото дефектов, электронная подпись клиента, назначение механиков, дополнительные согласования после старта ремонта, связка со складом и кассой, системные PostgreSQL проверки. Все перечисленное блокирует DONE.
