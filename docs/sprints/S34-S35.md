# S34–S35: подготовка выдачи и гарантийные документы

Статус обоих спринтов: **CODE IMPLEMENTED / ACCEPTANCE PENDING / NO-GO**.

## S34: предвыдачная проверка
- `GET /api/v1/workorders/<uuid>/handover-readiness` доступен только в рамках tenant/branch и ролей.
- Проверяет ready, approved estimate, все задания, дополнительные неисправности, резервы, наличие счёта и задолженность, проекты актов приёмки/работ/выдачи.
- Явно показывает, что документы по-прежнему **не подписаны**, а **фискальные чеки не проверены**.
- `handover_allowed` жёстко false. Endpoint только информационный и не меняет статусы/деньги.
- Карточка заказ-наряда показывает чек-лист и причины блокировки.
- Тесты проверяют отсутствие ложной выдачи и запрет чужого tenant.

## S35: гарантийный документ
- Добавлен тип `warranty` в версионируемые бланки, миграция 0005.
- Доступен проект гарантийной памятки по выполненному заказу, как и другие документы; используется сохранённый снимок с SHA-256.
- Он **не назначает произвольный гарантийный срок** и не подтверждает факт выдачи клиенту.
- Добавлен регрессионный тест запрета формирования гарантийной памятки в черновике.
