# S12: Платформа SaaS — IN PROGRESS

Созданы Plan, Subscription, миграция и read-only API тарифов и статуса подписки. Логика возвращает restricted при отсутствии подписки и read_only при истекших датах. SaaS-платежи отделены от кассы СТО.

**Не готово:** обязательная серверная блокировка всех записывающих бизнес API, безопасный lifecycle trial/active/grace/read_only, защищённый webhooks с криптопроверкой провайдера, платёжные операции и сверка, лимиты тарифов, self-service onboarding и интерфейс владельца SaaS.

Пока нет enforcement middleware, поле access в GET-интерфейсе НЕ ограничивает доступ в рабочем CRM API. Никакой коммерческий запуск не допускается. Тесты с PostgreSQL и проверка миграций не выполнены.
