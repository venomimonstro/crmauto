# ADR-001: модульный монолит
Статус: принято для технического каркаса.
- Django 5.2 LTS + DRF, PostgreSQL источник истины, React/TypeScript.
- Склад и финансы в PostgreSQL-транзакциях; фоновые уведомления через transactional outbox.
- Запрет прямого изменения ledger из браузера.
- Микросервисы и внешняя шина событий отклонены до реальной потребности.
- Backend API /api/v1; frontend отдельно на этапе разработки, через единый origin при публикации.
- Нельзя считать отсутствие POSTGRESQL, MFA SaaS администратора и восстановления приемлемым для production.
